Dati Raw

Questa pagina raccoglie i link ai file prodotti dalla pipeline. Il report interattivo mostra aggregazioni e grafici; per replicare un conteggio, controllare una singola homepage o costruire incroci diversi conviene partire dai file raw.

File Principali

  • summary.csv
    CSV sintetico, una riga per ente/homepage. E il file piu comodo per filtri, pivot e controlli rapidi.

  • framework_detection.jsonl
    Output completo della detection, una riga JSON per record. Include evidenze, score per tecnologia, framework primario, framework secondari, CMS, UI framework, conteggi JS/CSS e confidenza.

  • framework_summary.json
    Aggregato compatto con conteggi per framework primario, framework secondari, CMS e UI framework.

  • homepages.jsonl
    Esito del probing delle homepage: URL normalizzate, stato della risposta e metadati raccolti prima della detection.

  • js_inventory.jsonl
    Inventario degli script osservati per homepage.

  • css_inventory.jsonl
    Inventario dei fogli di stile osservati per homepage. E` utile per verificare i UI framework, inclusi Bootstrap Italia, Bootstrap, Elementor, Tailwind CSS, Foundation e UIkit.

  • js_downloads.jsonl
    Esito del download dei bundle JavaScript deduplicati. Alimenta le evidenze content: usate dal detector.

Estratti Per Le Domande Ricorrenti

  • question_ui_by_cms_framework.csv
    Incrocio tra ui_frameworks e piattaforma primaria. Usa cms_primario quando presente, altrimenti framework_primario, altrimenti il bucket Nessun primario.

  • question_tailwind_sites.csv
    Elenco dei record in cui ui_frameworks contiene Tailwind CSS.

  • question_angular_react_sites.csv
    Elenco dei record in cui Angular e React compaiono insieme tra framework_primario e framework_secondari.

Come Scegliere Il File

Per un controllo veloce usa summary.csv: e` leggibile con fogli di calcolo, DuckDB, pandas o qualsiasi strumento CSV.

Per capire perche una tecnologia e stata assegnata usa framework_detection.jsonl: il campo evidenze mostra quali marker sono stati trovati, mentre technology_scores conserva i punteggi intermedi usati dal detector.

Per ricostruire un grafico aggregato usa framework_summary.json o rigenera l'aggregazione da framework_detection.jsonl.

Per verificare un UI framework parti da css_inventory.jsonl e poi confronta il record corrispondente in framework_detection.jsonl.
