Dati Raw

Questa pagina raccoglie i file pubblicabili prodotti dalla pipeline. Le versioni scaricabili da qui sono anonimizzate: non espongono le URL delle homepage e, nelle evidenze, non espongono host o path degli asset dei siti.

File Principali

Estratti Per Le Domande Ricorrenti

Cosa Viene Anonimizzato

Nei file pubblici:

  • homepage_url viene rimossa.
  • Gli URL degli asset non vengono esposti.
  • Le evidenze vengono ridotte alla forma fonte:marker, per esempio content:react o css-url:bootstrap-italia.
  • Restano disponibili ente, tipologia, tecnologie rilevate, conteggi, score e livello di confidenza.

Questa scelta permette di verificare la logica di detection senza pubblicare una lista direttamente navigabile dei siti e dei loro asset.

Come Scegliere Il File

Per un controllo veloce usa public-summary.csv: e' leggibile con fogli di calcolo, DuckDB, pandas o qualsiasi strumento CSV.

Per capire perche' una tecnologia e' stata assegnata usa public-framework-detection.jsonl: il campo evidenze mostra quali marker sono stati trovati, mentre technology_scores conserva i punteggi intermedi usati dal detector.

Per ricostruire un grafico aggregato usa public-framework-summary.json o rigenera l'aggregazione da public-framework-detection.jsonl.
